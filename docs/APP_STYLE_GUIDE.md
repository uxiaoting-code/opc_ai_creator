# App 视觉风格说明（Light Premium）

> 参考原型：`D:\项目说明文档\AI聚合平台-预览\AI电商创作-原型-单文件.html`
>
> 目标：把用户端 Flutter App 改成“暖白 + 鼠尾草绿 + 香槟金”的
> Light Premium 风格，同时**不改变 `lib/` 的目录结构**。

---

## 1. 一句话记住风格

> 暖白底、鼠尾草绿做主色、香槟金做点缀、灰褐做次级文字、毛玻璃卡片、大圆角、柔和阴影。

不要把界面做成纯白底 + 高饱和紫/蓝，也不要大面积用纯黑。

## 4. 新页面怎么保持一致

1. **背景**：用 `Theme.of(context).scaffoldBackgroundColor`，不要自己写纯白。
2. **卡片**：优先用 `Card` / `Container` + `AppColors.radiusCard` + 白色细边 + `AppColors.shadowSoft`。
3. **主按钮**：用 `AppColors.primaryGradient` 或 `FilledButton`（主题已经是鼠尾草绿）。
4. **强调数字**：算力、价格、等级用 `AppColors.gold`。
5. **次级文字**：用 `Theme.of(context).textTheme.bodySmall`（已经是灰褐）。
6. **选中态**：用 `AppColors.sageTint` 做胶囊底，文字用 `AppColors.sage`。
7. **不要**在页面里写新的紫色/蓝色/粉色十六进制色值。
8. **不要**把整个页面做成深色；深色只用于视频播放器、图片预览这种沉浸场景。

## 5. 已改动的部分

- 全局色板从“电光紫 + 青蓝”换成“鼠尾草绿 + 香槟金”。
- 页面背景改成暖白 `#F7F7F5`。
- 底部导航改成半透明毛玻璃 + 鼠尾草绿选中胶囊。
- 首页头像、算力、消息、搜索框改成毛玻璃小卡片。
- 首页新增“灵感输入”Hero 卡：文生图/图生视频切换、提示词、线路/尺寸/数量胶囊、生成按钮。
- 首页新增“创作工具”场景快捷入口，点一下就把预设提示词带进创作页。
- 首页“最近作品”从横滑改成两列作品网格，更接近原型排版。
- 首页输入的提示词会通过路由参数带到创作页并自动填入，不用再复制一遍。
- 文生图创作页按原型重排：图片/视频模式切换、玻璃提示词卡、灵感示例、风格芯片、比例/清晰度弹层、底部固定生成栏。
- 风格、比例、清晰度不是摆设，会真正拼进提交给后端的提示词；视频页保留首帧图上传和运镜参数，并加了图片/视频切换。
- 当前后端没有音频生成接口，所以原型里的“音频”模式暂不放入；每次任务固定生成 1 张，页面已明确标注。
- 首页创作入口改成“毛玻璃卡片 + 渐变图标块”。
- 创作线路卡片、功能入口卡片改成毛玻璃 + 白色细边 + 柔和阴影。
- 无封面时的占位图改成暖色/莫兰迪渐变，图标改成柔炭黑。
- 文生图 / 图生视频的输入框改成 16 圆角、半透明底。
- 主生成按钮改成胶囊形、鼠尾草绿到香槟金的渐变。
- Flutter Web 外壳的 manifest 主题色同步成暖白/鼠尾草绿。
- 全局滚动改成 iOS 橡皮筋回弹，页面切换使用 Cupertino 推入动画。
- 去掉 Material 放射水波纹，改成更克制的按压高亮 + 触感反馈。
- 底部 Tab、个人中心入口、设置页主题切换改用 Cupertino 图标/分段控件。
- 关键点击（Tab、模式切换、生成、主题切换）加了触感反馈。
- AppBar 改成更轻的 iOS 风格：48 高、左对齐 20px 标题。
- 设置页/个人中心的信息卡改成 iOS 分组卡片：毛玻璃底、白边、柔和阴影。

## 6. 验证方式

```powershell
flutter analyze
flutter test
flutter run -d chrome
```

重点看：

- 首页顶部栏在 360×800 小屏不溢出。
- 底部导航选中态是鼠尾草绿，不是紫色。
- 所有卡片是暖白/半透明，不是纯白硬边。
- 文生图、图生视频的输入框和生成按钮风格一致。
- 深色模式下文字仍然可读。

> 注意：`web/` 是 Flutter Web 的启动壳，`admin-web/` 才是后台管理界面。
> 这次改的是 `lib/` 里的用户端 App，没有动后台页面结构。
