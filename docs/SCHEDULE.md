### D.1 P0 状态一致性整改（2026-11-05）

**触发原因：** 当前 `SUBMITTED` 接单会占用新接单资格，但 Flutter 启动后不会恢复当前订单，`admin-web` 又没有作品审核入口，导致用户无法继续订单、无法接新单，运营也无法处理待审核作品。

**业务口径（前后端统一）：**

- `ACCEPTED`：用户制作中，占用接单资格，可以创作。
- `REJECTED`：作品被驳回，未过截止时间时继续占用资格，可以重新创作和提交。
- `SUBMITTED`：用户工作已完成、等待运营审核，不占用新接单资格。
- `APPROVED`、`CANCELLED`：终态，不占用接单资格。
- 过期订单不能新接单、继续生成或提交作品；过期且仍为 `ACCEPTED/REJECTED` 的接单应自动转 `CANCELLED`。
- 截止前已提交的 `SUBMITTED` 作品仍可审核和入账，但不得阻塞用户接新单。
- 有 `ACCEPTED/REJECTED` 订单时，从工作台或创作首页发起的生成必须自动绑定当前 `orderId`。

## 9. Git 纪律

4. 搭档接接口前必须 pull 并读变更记录。
5. 不在 GitHub 网页直接改文件。
6. 不为赶进度删除旧文件或执行 Git reset。
