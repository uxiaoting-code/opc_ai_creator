OPC AI创作平台 - 完整接口文档
一、文档说明
本文档为 OPC AI 智能创作平台前后端交互接口文档，适用于前端 Flutter 与后端 SpringBoot 联调。项目主要实现 文本生成图片、图片生成视频、创作记录查询 核心功能。
所有接口统一使用 JSON 数据格式，请求与返回规范统一、结构清晰，可直接用于开发调试、课程设计报告、项目展示。
二、基础信息
- 后端服务地址：http://127.0.0.1:8080
- 请求数据格式：application/json / multipart/form-data
- 响应数据格式：统一 JSON 格式
- 接口协议：HTTP
- 跨域支持：全局开启跨域，支持前端 Flutter 本地调试
三、统一返回结果规范
后端所有接口返回数据均遵循以下统一结构，方便前端统一解析、统一异常处理。
统一返回字段说明
- code：状态码（200成功、400参数错误、500服务器异常）
- msg：返回提示信息
- data：业务返回数据，成功返回对应实体/数组，失败为 null
通用成功示例
{
  "code": 200,
  "msg": "请求成功",
  "data": {}
}
通用失败示例
{
  "code": 500,
  "msg": "AI模型调用失败，请重试",
  "data": null
}
四、核心业务接口列表
1. 文本生成图片接口（文生图）
- 接口地址：/api/ai/text2image
- 请求方式：POST
- 接口描述：接收用户输入的文本提示词与图片尺寸，调用AI模型生成图片，返回图片在线链接

请求参数（JSON）
{
  "prompt": "蓝天白云下的赛博朋克城市，高清写实",
  "size": "1024*1024"
}
参数说明
- prompt：生成图片的描述提示词（必填）
- size：图片分辨率尺寸（可选，默认1024*1024）

返回数据示例
{
  "code": 200,
  "msg": "图片生成成功",
  "data": {
    "prompt": "蓝天白云下的赛博朋克城市，高清写实",
    "imageUrl": "https://xxx.xxx/xxx.png"
  }
}
2. 图片生成视频接口（图生视频）
- 接口地址：/api/ai/image2video
- 请求方式：POST
- 提交方式：表单文件上传（multipart/form-data）
- 接口描述：接收用户上传的图片与辅助描述词，调用AI视频生成模型，返回生成视频在线地址
请求参数
- image：用户上传的图片文件（必填）
- prompt：视频风格、动作描述词（可选）
返回数据示例
{
  "code": 200,
  "msg": "视频生成成功",
  "data": {
    "taskId": "video_20260921_001",
    "videoUrl": "https://xxx.xxx/xxx.mp4"
  }
}
3. 查询AI创作历史记录接口
- 接口地址：/api/ai/history/list
- 请求方式：GET
- 接口描述：查询用户所有历史文生图、图生视频创作记录，按时间倒序返回
返回数据示例
{
  "code": 200,
  "msg": "查询成功",
  "data": [
    {
      "id": 1,
      "type": "text2image",
      "prompt": "海边落日猫咪",
      "resourceUrl": "https://xxx.xxx/xxx.png",
      "createTime": "2026-09-21 19:20:10"
    },
    {
      "id": 2,
      "type": "image2video",
      "prompt": "缓慢动态、轻微流动效果",
      "resourceUrl": "https://xxx.xxx/xxx.mp4",
      "createTime": "2026-09-21 19:25:30"
    }
  ]
}
五、状态码说明
- 200：接口请求成功，业务正常执行
- 400：参数缺失、参数格式错误
- 500：服务器异常、AI模型调用失败、接口异常
六、项目对接说明
1. 前端 Flutter 页面通过以上三个核心接口，完成全部业务交互；
2. 后端统一封装返回结果、全局跨域、全局异常捕获，保证前端对接稳定；
3. 所有生成的图片、视频资源为在线链接，前端可直接预览、展示、播放；
4. 历史记录接口用于实现个人创作中心，提升项目完整度与展示效果。
