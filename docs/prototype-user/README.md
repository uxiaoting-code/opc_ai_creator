# 用户端 Flutter 复刻参考原型

> 来源：老师提供的移动端 HTML/CSS/JS 原型（2026-10-29 加入项目）。
> 本目录只作**用户 App 视觉、交互和页面结构参考**，不是生产代码，也不是后台控制台。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 分文件版入口，浏览器打开即可预览 |
| `css/style.css` | 原型的颜色、间距、圆角、阴影、组件样式和页面布局 |
| `js/app.js` | 原型的数据、页面渲染、路由和交互逻辑 |
| `AI电商创作-原型-单文件.html` | 离线单文件版，内容和分文件版基本一致，方便直接打开 |

## 和 Flutter App 的关系

- 最终交付物：`lib/` 下的 Flutter 用户 App。
- 原型中的 28 个 screen 用于逐页对照，不应直接嵌入 Flutter。
- Flutter 页面只调用后端 `/api/**`；API Key、AI Provider 和 Harness 调用都留在 `server/`。
- 页面数据通过 repository/API 获取，组件只接收数据并发出回调，不直接写网络请求。

## 和后台控制台的区别

- 用户 App：`lib/`（Flutter）
- 运营后台：`admin-web/`（HTML/CSS/JS）
- 本目录：老师的用户 App HTML 参考，不是 `admin-web/`
